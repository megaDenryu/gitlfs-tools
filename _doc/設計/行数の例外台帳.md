# 行数の例外台帳

コード行で100行を超えることを許したファイルを登録する。グローバルCLAUDE.md
「1ファイル100行の原則と分割の質」が定める例外の管理簿である。

登録の条件は、分割すると1つの流れの一片になってしまうために統合したファイルであることである。
単一の関心事が自然に100行を超えた場合は登録の対象にならない。その場合の正しい対処は、
型自体のフィールドと責務を減らす再設計である。上限は150行であり、これを超えたら登録できない。

数え方はコードの行だけである。空行と、コメントだけの行は数えない。

`cargo xtask check-line-count` が本台帳と実際の行数の両方を検査する。**台帳に登録されているのに
100行以内へ収まったファイルも違反として報告される。** 例外は放置すると増える一方であるため、
減らす方向の力を仕組みで用意している。収まったら台帳から削除する。
